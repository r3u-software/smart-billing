🔐 Access codes

Each department's code is generated automatically from your Administrator password — you don't set them, and they're the same on any device you sign in from. Give each team its code; members see only their own data. Rotate issues fresh codes; Change admin password updates the master. After either, click Sync to publish.

⛃ Backup & Restore

A plain-JSON safety copy of your parsed data + user mapping + departments (kept private — not the shared file). Restore rebuilds from it. Different from Sync, which publishes the encrypted data to GitHub.

🔄 Sync — publish encrypted data to GitHub (one click)

Pushes the encrypted files straight to your repo — no manual commit. Create a fine-grained Personal Access Token (GitHub → Settings → Developer settings → Fine-grained tokens) scoped to only this repo with Contents: Read and write, then paste it below. Stored on this machine only.
